# Zomato Food Delivery Database Analysis using MySQL

## Project Overview

This project focuses on designing and analyzing a relational database system for a food delivery platform inspired by Zomato.

The project uses MySQL to store customer details, restaurant information, orders, food products, and delivery details.

The main objective is to practice SQL concepts and answer real-world business questions using database queries.

## Technologies Used

- MySQL
- MySQL Workbench
- Git and GitHub

## Database Structure

The project consists of 6 tables:

1. Customers – Stores customer information.
2. Restaurants – Stores restaurant details and ratings.
3. Orders – Stores customer order information.
4. Deliveries – Stores delivery details.
5. Products – Stores food product information.
6. Order_Items – Connects orders with their respective food items.

## SQL Concepts Covered

- Database and Table Creation
- Primary Keys and Foreign Keys
- Data Types and Constraints
- INSERT, UPDATE and DELETE
- SELECT and WHERE
- Aggregate Functions
- GROUP BY and ORDER BY
- JOIN Operations
- Subqueries
- Date and Time Functions

## Business Questions

The project aims to answer 10 business questions, including:

1. Top 5 highest-spending customers.
2. Most ordered restaurant in Bangalore.
3. Month-wise total sales.
4. Customers who never placed an order.
5. Restaurants with ratings above 4.5.
6. Average delivery time.
7. Total orders placed by each customer.
8. Most ordered food item.
9. Weekend vs weekday sales comparison.
10. Delivery partner with the highest number of deliveries.

Currently in development. Database design and SQL query implementation are in progress.
